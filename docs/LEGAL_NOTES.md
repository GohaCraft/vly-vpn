# Внутренние заметки по юридической части (НЕ для публикации)

> Это рабочие заметки для команды, а не юридический документ и не консультация.

## ⚠️ ГЛАВНОЕ — не перепутать два разных риска

**PRIVACY.md и TERMS.md защищают от: удаления из сторов, жалоб пользователей,
гражданских исков, претензий по данным. Они НЕ защищают от
уголовно-административной ответственности за сам сервис обхода блокировок.**

Личный риск оператора — это отдельная проблема, которая решается **структурой
юрлица и оценкой с живым юристом**, а НЕ текстом политики. Публикация красивых
документов под именем физлица идентифицирует оператора и может ухудшать личный
риск, а не улучшать.

## Решить с юристом ДО публикации/монетизации (в порядке важности)

1. **Кто оператор и в какой юрисдикции.** Определяет применимое право и личный
   риск. Не издавать под именем физлица без консультации.
2. **Оплата = идентификация.** Любой легальный платёжный провайдер обязан
   провести KYC/AML и идентифицировать получателя средств. «Принимать деньги
   анонимно» — фундаментальный конфликт, не настройка. **Не включать оплату/
   подписку/донаты до решения с юристом.**
3. **Заявления в политике должны быть правдивы буквально.** Если написано «не
   логируем трафик» — это должно выполняться на 100% (у нас — да). Ложные
   обещания = обман потребителя + основание для санкций сторов.
4. **Требования сторов.** Google Play / App Store требуют URL политики +
   Data Safety декларацию + раскрытие VPN-функциональности; формулировки должны
   совпадать с декларацией.
5. **GDPR** — расширить раздел прав, если есть пользователи из ЕС.

## Где взять юридическую помощь недорого

- Нужен **точечный** объём: (1) разовая консультация по риску/структуре,
  (2) ревью готовых PRIVACY.md/TERMS.md. Не ретейнер.
- **Access Now Digital Security Helpline** — бесплатно, по-русски, для людей в
  зоне риска и разработчиков инструментов обхода цензуры: help@accessnow.org.
- **EFF** (Coders' Rights Project) — профильная тема.
- Профильные цифровые-права организации по РФ-контексту специализируются на этом,
  НО часть из них в РФ помечена «иноагентом»/«нежелательной» — контакт изнутри РФ
  может добавлять риска; взвешивать индивидуально.
- Искать юриста с бесплатной первичной консультацией и фиксированной ценой за
  задачу; юр-клиники при вузах и pro bono — бесплатные варианты.

Требуют вычитки юристом и английской версии для сторов перед публикацией.
